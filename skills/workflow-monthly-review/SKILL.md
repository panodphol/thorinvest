# Monthly Review

1. Returns and attribution (`performance-attribution`, `thor-calc` attribution + linking tools).
2. Risk-adjusted metrics and peers; contribution/detraction top/bottom 5.
3. Reconcile: attribution total = active return; flag residual > 5 bp.
4. Commentary — signal first, bp everywhere, skill vs style, what changes next month.
5. Assemble (`kasset-visual-system`); client versions via `client-communication` + `compliance_precheck`.

Pack specs: `references/procedures/perf-006.md` (monthly), `references/procedures/perf-014.md` (deep).
