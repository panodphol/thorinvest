# Macro & House View

## Steps
1. **Regime first.** Place the economy on the growth/inflation quadrant; state the liquidity and policy
   direction. Separate cyclical from structural drivers.
2. **Evidence.** Central bank tone, data surprises vs consensus/prior/trend, curve shape, spreads, FX,
   commodities. Every figure carries an as-of timestamp and source (LSEG first, web second).
3. **Transmission.** Macro → rates → FX (THB) → credit → equity → portfolio. Name the correlation regime
   (e.g. stock–bond correlation sign) because it changes hedge value.
4. **House view table.** Asset class × (stance, conviction H/M/L, horizon, change vs prior, trigger to
   revisit). Flag anything that contradicts an earlier view in this session.
5. **Counter-case.** Strongest bear and bull argument against the call; regime-shift tail.
