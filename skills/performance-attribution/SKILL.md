# Performance & Attribution

## Steps
1. **Returns basis.** Gross/net, currency, period, benchmark; TWR vs MWR stated.
2. **Attribute with tools.** `thor-calc.performance_attribution` per period, `thor-calc.link_attribution`
   across periods. Allocation + selection + interaction must reconcile to active return (show residual).
3. **Decompose further** only when it changes the story: factor, FI (duration/curve/spread), FX
   (Karnosky-Singer view comes from `portfolio-construction`).
4. **Narrative.** What worked, what did not, whether it was skill or style, what we change. Numbers in bp.
